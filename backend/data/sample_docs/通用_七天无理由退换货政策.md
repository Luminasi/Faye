# 全平台通用 · 七天无理由退换货政策

## 适用范围
凡在本电商平台（以下简称"平台"）所购的商品，均适用《消费者权益保护法》规定的"七日无理由退货"。

## 一、时间计算
自买家签收商品次日 0 时起算，7 个自然日（168 小时）内，买家可申请无理由退货。

## 二、无理由退货条件
1. 商品本身完好，外观无划痕、无磕碰、无使用痕迹
2. 配件、赠品、发票、包装等完整齐全
3. 定制类、鲜活易腐、音像制品拆封后、数字化商品已下载、个人贴身内衣、拆封后易贬值的商品不适用七天无理由
4. 大型家电如已上门安装，需自行承担拆机费及往返运费

## 三、运费承担
- 因买家个人原因无理由退货：运费由买家承担，订单含运费险可按理赔规则抵扣
- 因质量问题、发错货、与描述不符导致的退换货：往返运费由商家承担

## 四、退款时效
平台收到退回商品并验收无误后，将在 **1~3 个工作日** 内将退款按原支付路径退回。银行卡/信用卡退款可能需银行处理 3~7 个工作日。

## 五、退货流程
1. 登录 APP → 我的订单 → 对应订单 → 申请售后 → 选择"七天无理由"
2. 填写退货原因，提交
3. 商家审核通过后（48 小时内）获取退货地址
4. 自行寄回或上门取件，填写物流单号
5. 商家签收后 24 小时内完成验收，之后退款

## 六、客服

- 在线客服入口：APP 底部「我的」→「客服中心」
