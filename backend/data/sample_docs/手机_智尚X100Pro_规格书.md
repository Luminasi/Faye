# 手机类商品规格书 · 智尚 X100 Pro

## 一、产品概述
智尚 X100 Pro 是 2025 年推出的旗舰级 5G 智能手机，主打影像能力与长续航。

## 二、核心规格
- 型号：ZS-X100Pro
- 上市时间：2025 年 1 月
- 操作系统：MyOS 16（基于 Android 15）
- 处理器：天玑 9400 旗舰芯片（3nm 工艺）
- 运行内存：12GB / 16GB LPDDR5X
- 机身存储：256GB / 512GB / 1TB UFS 4.1
- 屏幕：6.78 英寸 AMOLED 2K 曲面屏，峰值亮度 4500nit，支持 LTPO 1-120Hz 自适应刷新率
- 前置摄像头：3200 万像素，自动对焦
- 后置摄像头：
  - 主摄 1 英寸大底 5000 万像素 OIS
  - 超广角 4800 万像素
  - 潜望长焦 6400 万像素 5X 光学变焦，最高 100X 数字变焦
- 电池容量：5600mAh 硅碳负极大电池
- 充电：有线 120W 超级快充，50W 无线快充，10W 反向无线充电
- 5G 网络：双卡双待双通，支持 NR/NSA
- 机身：IP68 防水防尘，航空级铝合金中框，素皮/陶瓷两种后盖
- 重量：素皮版 218g，陶瓷版 234g
- 生物识别：光学屏下指纹、面部识别
