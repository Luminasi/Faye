# 笔记本电脑 · 星瀚 P15 参数

## 产品定位
面向学生与办公人群的高性能轻薄本。

## 核心参数
- 型号：StarBook P15
- CPU：Intel Core Ultra 7 258H（16 核 22 线程，睿频 4.8GHz）
- GPU：Intel Arc Xe2 核显 + 可选 NVIDIA RTX 4060 8GB 独显
- 内存：16GB / 32GB LPDDR5X 7467MT/s（板载，不可扩展）
- 存储：512GB / 1TB / 2TB PCIe 4.0 NVMe SSD，双 M.2 插槽，最大可扩展至 4TB
- 屏幕：15.6 英寸 2.5K（2560×1600）IPS，240Hz 刷新率，100% DCI-P3 广色域，500nit 亮度，低蓝光认证
- 尺寸：355 × 241 × 16.9 mm
- 重量：1.82 kg（独显版 1.95 kg）
- 电池：75Wh 大容量，标配 90W PD 适配器
- 续航：本地视频播放约 14 小时，日常办公约 8 小时

## 接口
- 左侧：2 × Thunderbolt 4（全功能 Type-C）、1 × USB 3.2 Gen2 Type-A、3.5mm 二合一音频口
- 右侧：1 × USB 3.2 Gen2 Type-A、1 × HDMI 2.1、1 × SD 读卡器、RJ45 千兆网口
- 支持 Wi-Fi 7 + 蓝牙 5.4
